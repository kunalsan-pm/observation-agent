## Q10 · Patterns

> Are there any associates whose recent scores have declined meaningfully against their own earlier baseline?

**Tool call**

```python
find_score_declines()
```

**Definition applied:** mean of last 3 observations vs mean of all prior (>= 3). Meaningful when **drop >= 5.0 points AND drop >= 2.0 baseline SDs**.
Baseline SD is floored at 1.0 point so a near-flat history cannot manufacture a huge z from a trivial move.

*Why:* Self-referential baseline, because a decline from a high level is invisible against a cohort. Two tests together: the absolute test keeps the finding worth a manager's time, the volatility test keeps it distinguishable from that person's normal variation.
